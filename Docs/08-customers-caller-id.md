# مشتریان و Caller ID

## پروفایل
نام، چند شماره، آدرس‌های متعدد، یادداشت، تاریخچه سفارش، سطح مشتری، تخفیف اختصاصی و ترجیحات مجاز.

## تشخیص خودکار
Caller ID شماره را دریافت می‌کند؛ سامانه شماره را Normalize و مشتری را پیدا می‌کند. در حالت چند تطبیقی، انتخاب دستی نشان داده شود.

## سفارش تلفنی
تماس → شناسایی → آدرس → سفارش → تأیید شماره و آدرس → محاسبه → ثبت → ارسال.

## حریم خصوصی
اطلاعات تماس فقط برای نقش‌های مجاز نمایش داده شود و دسترسی‌های حساس Audit شوند.
