# Release Notes — 006.4.1.0

## POS و ثبت سفارش

- اتصال Route اصلی `?page=orders` به صفحه اختصاصی POS.
- انتخاب مشتری با شماره تلفن یکتا.
- حفظ مشتری انتخاب‌شده هنگام افزودن، حذف یا خالی‌کردن سبد.
- افزودن محصول با کلیک و افزایش خودکار تعداد.
- محاسبه لحظه‌ای مبلغ فاکتور.
- انتخاب شیوه پرداخت نقدی، کارتخوان، آنلاین یا ترکیبی.
- صدور شماره یکتای سفارش، فاکتور و پرداخت.
- ثبت سفارش، آیتم‌ها، فاکتور و پرداخت داخل یک تراکنش MariaDB.

## مشتریان

- اتصال Route اختصاصی `?page=customers` به View اختصاصی مشتریان.
- فیلدهای کد اشتراک، نام، نام خانوادگی، شماره تلفن، تلفن همراه، تاریخ عضویت، آدرس و تاریخ تولد.
- یکتایی شماره تلفن در Database.
- ورود گروهی مشتریان از CSV.

## محصولات و منو

- اتصال Route اختصاصی `?page=products` به View اختصاصی محصولات.
- فیلدهای فعال، قیمت واحد، واحد، نوع کالا، نام کالا و کد کالا.
- یکتایی کد کالا در Database.
- ورود گروهی محصولات از CSV.

## تاریخ و داده

- تبدیل تاریخ شمسی ورودی CSV و فرم به تاریخ میلادی برای ذخیره در Database.
- نمایش تاریخ‌های رابط کاربری به تقویم شمسی و ارقام فارسی.
- اصلاح Namespace مربوط به `PersianDate` در `CsvController`.
