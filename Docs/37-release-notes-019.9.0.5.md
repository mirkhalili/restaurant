# Release Notes — 019.9.0.5

## هدف
بهبود تجربه ثبت سفارش، یکپارچه‌سازی نمایش تعداد محصولات و تکمیل تنظیمات فیش آشپزخانه.

## تغییرات

1. **حفظ فیلتر نوع محصول در ثبت سفارش**
   - نوع محصول انتخاب‌شده توسط کاربر در Session نگهداری می‌شود.
   - پس از افزودن محصول و Refresh صفحه، فیلتر به «همه» برنمی‌گردد.
   - فیلتر فقط با انتخاب دستی کاربر تغییر می‌کند.

2. **تعداد محصولات فقط به‌صورت عدد صحیح**
   - ثبت سفارش، ویرایش فاکتور و چاپ فیش از مقدار صحیح استفاده می‌کنند.
   - گزارش پرفروش‌ترین محصولات نیز تعداد را بدون اعشار نمایش می‌دهد.

3. **بهبود فیش آشپزخانه**
   - عنوان پیش‌فرض فیش: «آشپزخانه کوچک»
   - نوع سفارش «سالن» یا «بیرون‌بر» با اندازه بزرگ چاپ می‌شود.
   - نام مشتری در فیش آشپزخانه نمایش داده می‌شود.
   - شماره فاکتور و نام رستوران قابل کنترل هستند.
   - تعداد هر محصول بدون اعشار چاپ می‌شود.

4. **تنظیمات مستقل فیش آشپزخانه**
   - عنوان فیش آشپزخانه
   - نمایش نام رستوران
   - نمایش نوع سفارش
   - نمایش نام مشتری
   - نمایش شماره فاکتور
   - نمایش تاریخ
   - نمایش/عدم نمایش گروه‌بندی نوع محصول
   - متن پایانی فیش
   - تنظیمات فیش آشپزخانه با تنظیمات فیش مشتری مستقل ذخیره می‌شوند.
