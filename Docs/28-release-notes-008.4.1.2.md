# Release Notes — 008.4.1.2

## CSV Encoding Fix

- رفع خطای `mb_convert_encoding()` ناشی از استفاده از نام Encoding نامعتبر `Windows-1256`.
- جایگزینی با نام معتبر `CP1256` برای سازگاری با PHP `mbstring`.
