# الزامات غیرعملکردی

## کارایی
عملیات POS رایج باید سریع و قابل پیش‌بینی باشد. جستجوها با Index مناسب طراحی شوند.

## قابلیت اطمینان
قطع چاپگر نباید سفارش را از بین ببرد؛ Print Job قابل Retry باشد.

## همزمانی
دو صندوق نباید شماره سند یا موجودی را ناسازگار مصرف کنند.

## پشتیبان
Backup خودکار و Restore Test دوره‌ای.

## امنیت
Least Privilege، Audit، Session Security و Validation سمت سرور.

## مقیاس
چند شعبه و چند صندوق بدون بازطراحی هسته.

## نگهداری
Migration، تست واحد و یکپارچه، API Documentation و ADR.
