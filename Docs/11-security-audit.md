# امنیت و Audit

## احراز هویت
Session امن، Password Hash، PIN برای POS، خروج خودکار، محدودیت نشست و امکان MFA در آینده.

## مجوز
RBAC + Permission. Backend/API نیز باید مجوز را بررسی کند و UI به‌تنهایی مرز امنیتی نیست.

## Audit
برای رویدادهای حساس ثبت شود: چه کسی، چه زمانی، از کجا، چه عملیاتی، چه رکوردی، مقدار قبل/بعد در صورت امکان و علت.

## رویدادهای مهم
ورود، خروج، تغییر نقش، تغییر قیمت، حذف یا ابطال، برگشت وجه، اصلاح موجودی، تغییر تنظیمات چاپ و سیستم و تغییر Permission.

## حذف
اسناد مالی Void/Soft Delete شوند. حذف فیزیکی فقط برای داده‌های غیرمالی و طبق سیاست نگهداری.

## حفاظت
CSRF، XSS، SQL Injection، Rate Limit، Validation سمت سرور، محدودیت آپلود، بررسی MIME، نام امن فایل و جلوگیری از اجرای فایل آپلودی.
