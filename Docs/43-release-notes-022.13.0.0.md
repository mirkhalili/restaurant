# Release Notes — 022.13.0.0

## فیش آشپزخانه
- چیدمان فیش آشپزخانه بر اساس الگوی پیوست تنظیم شد.
- سربرگ شامل «آشپزخانه»، شماره فیش و نشان آشپزخانه است.
- نوع سفارش با نمایش بزرگ «سالن / بیرون‌بر» چاپ می‌شود.
- مشتری و تاریخ/ساعت در ردیف‌های جداگانه نمایش داده می‌شوند.
- جدول سه‌ستونه «نوع سفارش / سفارش / تعداد» ثابت و بدون بیرون‌زدگی است.
- جداکننده بین گروه‌های غذایی ضخیم‌تر است.
- عنوان گروه مانند «غذای اصلی» در ستون سفارش پررنگ است و نام اقلام با وزن فونت عادی چاپ می‌شود.
- چاپ از QZ Tray مستقل شد و از `window.print()` جاوااسکریپت مرورگر استفاده می‌کند؛ امکان چاپ فیش مشتری، فیش آشپزخانه یا هر دو وجود دارد.

## انبار و کنترل موجودی
- ماژول واقعی «انبار و کنترل موجودی» جایگزین placeholder شد.
- ثبت کالای انبار، واحد، موجودی فعلی، حد سفارش و وضعیت کنترل موجودی اضافه شد.
- امکان افزایش/کاهش دستی موجودی با ثبت گردش انبار اضافه شد.
- برای هر محصول می‌توان چند کالای مصرفی و «مقدار مصرف در هر سفارش» تعریف کرد.
- هنگام نهایی‌کردن سفارش، موجودی کالاهای کنترل‌شده به‌صورت تراکنشی و با قفل رکورد کم می‌شود.
- اگر موجودی برای یک سفارش کافی نباشد، ثبت سفارش نهایی متوقف و پیام دقیق نمایش داده می‌شود.
- کالاهایی که کنترل موجودی ندارند، نه کسر می‌شوند و نه در هشدار تأمین قرار می‌گیرند.
- کالاهایی که موجودی کنترل‌شده آن‌ها برای یک سفارش کافی نباشد، از صفحه سفارش نمایش داده نمی‌شوند.
- فهرست «نیاز به تأمین / لیست سفارش خرید» بر اساس حد سفارش ایجاد شد.

## پوسته روز و شب
- منطق تغییر تم مقاوم‌تر شد و در صورت خطای localStorage نیز دکمه از کار نمی‌افتد.
- آیکن و عنوان دکمه بر اساس پوسته فعال تغییر می‌کند.
- نسخه‌گذاری URL فایل JavaScript برای جلوگیری از ماندن نسخه قدیمی در کش مرورگر اضافه شد.
