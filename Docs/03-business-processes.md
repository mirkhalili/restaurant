# فرآیندهای کسب‌وکار

## فروش حضوری
ورود کاربر → انتخاب نوع سفارش → انتخاب مشتری یا میز → افزودن اقلام → تخفیف مجاز → ثبت → ارسال آشپزخانه → چاپ → پرداخت → رسید → بستن سفارش.

## فروش تلفنی با Caller ID
تماس ورودی → دریافت شماره → جستجوی مشتری → نمایش پروفایل و سفارش‌های اخیر → ایجاد سفارش → تأیید آدرس → ثبت اقلام → ارسال.

## انبار
خرید یا ورود کالا → رسید → افزایش موجودی → مصرف بر اساس Recipe → کاهش موجودی → شمارش → ثبت مغایرت با مجوز.

## لغو
قبل از تسویه: لغو با علت.
بعد از تسویه: ابطال یا برگشت طبق مجوز مالی.
سند مالی نهایی حذف فیزیکی نشود.

## بستن شیفت
ثبت فروش → تطبیق نقد، کارت و آنلاین → شمارش صندوق → ثبت مغایرت → تأیید مسئول → قفل شیفت.

## پشتیبان
Backup زمان‌بندی‌شده → نگهداری نسخه‌ها → ثبت موفقیت/خطا → Restore فقط برای مدیر مجاز.
