# Release Notes — 010.5.0.0

## POS and CRUD UI/UX

- افزودن ویرایش و حذف مشتریان.
- افزودن ویرایش و حذف محصولات/منو.
- جستجوی مشتری در ثبت سفارش با نام، نام خانوادگی یا شماره تلفن.
- در صورت نبود مشتری، فرم کامل ثبت مشتری همان‌جا در صفحه ثبت سفارش نمایش داده می‌شود.
- پس از ثبت مشتری جدید، مشتری به‌صورت خودکار برای همان سفارش انتخاب می‌شود.
- نمایش مشخصات کامل‌تر مشتری در باکس فاکتور.
- محصولات POS به‌صورت کارت‌های کوچک‌تر و متراکم‌تر نمایش داده می‌شوند.
- رنگ کارت محصولات بر اساس عدد صدگان کد کالا گروه‌بندی می‌شود.
- نسخه با توجه به QAVNS به دلیل تغییرات بنیادی رابط کاربری و قابلیت‌ها: **010.5.0.0**.
