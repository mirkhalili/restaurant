# نقش‌ها و دسترسی‌ها

## نقش‌های پایه
| نقش | محدوده |
|---|---|
| مدیر سیستم | همه تنظیمات، کاربران و دسترسی‌ها |
| مدیر رستوران | عملیات و گزارش‌های مدیریتی |
| صندوقدار | سفارش، فاکتور و پرداخت طبق مجوز |
| انباردار | انبار، خرید، ورود و خروج |
| آشپز | مشاهده و تغییر وضعیت سفارش آشپزخانه |
| پذیرش | میز، سفارش و مشتری |
| اپراتور تلفن | Caller ID و سفارش تلفنی |
| حسابدار | مالی و گزارش‌های مالی |
| گزارش‌گیر | مشاهده گزارش |
| کاربر سفارشی | مجموعه مجوز انتخابی |

## مدل مجوز
مجوزها بر اساس Resource + Action تعریف شوند، مانند orders.create، orders.edit، orders.cancel، invoices.refund، inventory.adjust و settings.manage.

هر مجوز Scope داشته باشد: همه شعب، شعبه جاری، صندوق جاری یا رکوردهای مجاز.

## عملیات حساس
حذف، ابطال، برگشت وجه، تغییر قیمت، اصلاح موجودی، مشاهده اطلاعات مالی و تغییر مجوزها مجوز مستقل و Audit داشته باشند.
