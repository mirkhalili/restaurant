# راهنمای UI/UX

## اصول
- POS سریع و کم‌کلیک
- RTL واقعی
- مناسب مانیتور لمسی
- دکمه‌های بزرگ برای صندوق
- جستجوی سریع غذا و مشتری
- میانبر صفحه‌کلید
- Badge برای وضعیت
- Confirm برای عملیات مخرب
- Loading، Empty و Error State

## POS
سه ناحیه: دسته و جستجو، اقلام سفارش، خلاصه و پرداخت. در صفحه کوچک، خلاصه به Drawer تبدیل شود.

## جدول‌ها
جستجو، فیلتر، Sort، Pagination، انتخاب چندگانه و Export با Permission.

## فرم‌ها
Validation لحظه‌ای، پیام خطای فارسی و حفظ داده در زمان خطا.

## دسترس‌پذیری
کنتراست مناسب، Focus واضح، Keyboard navigation و عدم اتکا فقط به رنگ.
