# QAVNS در ریپو

قالب رسمی: `e0RSN.G.FF.CCC[-PRI][-BMD]`

- **e0RSN**: شماره ترتیب نشر؛ در هر انتشار دقیقاً یک واحد افزایش می‌یابد.
- **G**: شماره نسل نرم‌افزار.
- **FF**: قابلیت/محتوای غیر‌بنیادی و سازگار.
- **CCC**: رفع اشکال و اصلاحات.
- **PRI**: وضعیت ارائه مانند alpha، beta یا rc.
- **BMD**: فراداده ساخت در صورت نیاز.

## نسخه جاری

`003.3.0.0`

نسخه مبنای این تغییر `002.0.0.0` بوده است. انتقال معماری استقرار از Docker/محیط توسعه به استقرار مستقیم روی هاست اشتراکی، یک تغییر بنیادی زیرساختی محسوب می‌شود؛ بنابراین:

- e0RSN: از 002 به 003
- G: از 2 به 3
- FF: صفر
- CCC: صفر

## قواعد

- فقط Bug یا اصلاح ظاهری → CCC + 1.
- قابلیت جدید سازگار → FF + 1 و CCC=0.
- قابلیت جدید همراه Bug → FF + 1 و CCC=1.
- تغییر بنیادی در ساختار/UI/API/زیرساخت اصلی → G + 1 و FF=CCC=0.
- در هر نگارش e0RSN دقیقاً یک واحد زیاد می‌شود.
- نسخه منتشرشده بازنویسی نمی‌شود.
- نام branch باید با نسخه انتشار هماهنگ باشد.

## Git

branch این نسخه:

`feature/003.3.0.0`

پس از کنترل نهایی، Pull Request به `main` ایجاد و merge می‌شود. فایل `VERSION` و Release Notes باید با QAVNS هماهنگ باشند.

## نکته مهم

تغییرات استقرار این نسخه نباید با یک Patch روی نسخه قبلی بازنویسی شوند؛ این نگارش یک نسل جدید از ساختار اجرایی پروژه است.
