# معماری اطلاعات و Navigation

## عملیات
داشبورد، سفارش‌ها، صندوق و شیفت، فاکتورها، میزها و سالن، آشپزخانه.

## مدیریت
مشتریان، منو، غذاها و محصولات، تخفیف‌ها، انبار، خرید و تأمین‌کنندگان.

## تحلیل
گزارش فروش، گزارش مالی، گزارش مشتریان، گزارش انبار، Audit Log.

## زیرساخت
کاربران، نقش‌ها و مجوزها، شعب، دستگاه‌ها و چاپگرها، تنظیمات، Backup/Restore.

## قواعد
- Sidebar بر اساس فرکانس استفاده مرتب می‌شود.
- آیتم‌ها با Permission فیلتر می‌شوند.
- Breadcrumb از Navigation تولید می‌شود.
- URL هر صفحه پایدار و قابل Bookmark است.
- صفحات جزئیات از List → Detail → Edit پیروی می‌کنند.
