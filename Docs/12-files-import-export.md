# فایل، Import و Export

## Upload
تصویر غذا، سند خرید، پیوست مشتری و فایل‌های ماژول‌ها با Permission کنترل شوند.

## امنیت فایل
محدودیت حجم، Allowlist پسوند، بررسی MIME، نام تصادفی، جلوگیری از اجرای فایل و کنترل دسترسی دانلود.

## Import
CSV/XLSX با Preview، Validation، گزارش خطا، Batch و در عملیات مناسب Rollback.

## Export
CSV/XLSX/PDF بر اساس Permission و فیلتر جاری.

## Backup
Backup دیتابیس و فایل‌ها، وضعیت Job و سیاست Retention.
