# Release Notes — 017.9.0.3

## هدف
رفع خطای گزارشات و تکمیل تجربه سفارش، فاکتور، رویدادنگاری، عنوان رستوران و چاپ مستقیم مشتری/آشپزخانه.

## تغییرات
- رفع Fatal Error کلاس `App\\Http\\Controllers\\ReportsController` با اصلاح namespace و importها.
- مجوزهای محصول برای «سالن» و «بیرون‌بر» از این نسخه به‌صورت پیش‌فرض خاموش هستند.
- عنوان تیک‌های مجوز در فرم ایجاد/ویرایش محصول واضح شد.
- دکمه حذف مشتری از سفارش به بخش بالای فاکتور منتقل و به دکمه ضربدر تبدیل شد.
- عبارت «سالن» یا «بیرون‌بر» در بالای فاکتور بزرگ و بدون برچسب اضافی نمایش داده می‌شود.
- آیکون از کارت محصولات حذف و عنوان محصول بزرگ‌تر شد.
- تاریخ و فیلترهای رویدادنگاری به تقویم شمسی منتقل و گزینه «مشاهده» جزئیات فعال و واضح شد.
- عنوان HTML سایت و نام برند کناری بر اساس نام رستوران ذخیره‌شده در تنظیمات نمایش داده می‌شود.
- چاپ مستقیم با QZ Tray اضافه شد تا فاکتور مشتری به چاپگر پیش‌فرض سیستم و فیش آشپزخانه به چاپگر تعریف‌شده آشپزخانه ارسال شود.
- فیش مشتری با فونت Vazirmatn و فیش آشپزخانه بدون قیمت تولید می‌شود.
- فیش آشپزخانه محصولات را بر اساس نوع محصول تفکیک می‌کند، جداکننده دارد و تعداد را در اندازه بزرگ نمایش می‌دهد.
- Migration جدید: `009_product_order_type_defaults_zero.sql`.

## نکته چاپ
برای چاپ مستقیم بدون انتخاب چاپگر مرورگر، QZ Tray باید روی کامپیوتر صندوق نصب و در حال اجرا باشد. حذف کامل هشدار/اجازه QZ Tray نیز نیازمند تنظیم certificate و signing است.

## نکته نصب دیتابیس
Migration شماره 009 را بعد از Migration شماره 008 و فقط یک‌بار روی دیتابیس موجود اجرا کنید.
