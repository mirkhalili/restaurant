# Release Notes — 012.6.0.0

## تغییرات
- حذف گروهی محصولات با انتخاب چند محصول
- ایجاد مدیریت دسته‌بندی محصولات در تنظیمات
- انتخاب رنگ برای هر دسته‌بندی
- نمایش کارت محصولات POS بر اساس رنگ دسته‌بندی تنظیم‌شده
- جستجوی Ajax مشتری با نمایش نام و اطلاعات تماس
- نگهداری مشخصات مشتری انتخاب‌شده در بخش فاکتور
- تایپوگرافی خواناتر و پررنگ‌تر برای محصولات و اقلام فاکتور
- تبدیل خودکار ي به ی و ك به ک در ورودی‌های فارسی
- نرمال‌سازی داده‌های CSV
- migration برای اصلاح داده‌های موجود پایگاه‌داده و ایجاد ساختار دسته‌بندی

## مهاجرت پایگاه‌داده
