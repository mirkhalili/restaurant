# Release Notes — 018.9.0.4

## تغییرات
- نوع سفارش «سالن / بیرون‌بر» در فیش آشپزخانه با اندازه بزرگ نمایش داده می‌شود.
- تعداد اقلام در ویرایش فاکتور و چاپ به‌صورت عدد صحیح ذخیره/نمایش داده می‌شود و رقم اعشار ندارد.
- رنگ نوع محصول در کارت‌های ثبت سفارش دوباره در قالب کادر و نوار رنگی نمایش داده می‌شود.
- فیلتر نوع محصول در ثبت سفارش تا زمان تغییر دستی کاربر باقی می‌ماند؛ انتخاب چند محصول از یک نوع، کاربر را از همان فیلتر خارج نمی‌کند.
- تفکیک و جابه‌جایی نوع محصول فقط با انتخاب دستی فیلتر انجام می‌شود.
