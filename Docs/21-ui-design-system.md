# سیستم طراحی رابط کاربری

## Design Tokens
Spacing: 4، 8، 12، 16، 20، 24، 32، 40، 48px.  
Radius: 8، 12، 16، 20 و pill.  
Surface tokens: page، surface، muted، border، text-primary، text-secondary.  
Semantic tokens: primary، success، warning، danger، info.

## Components
Shell، Sidebar، Header، Breadcrumb، Card، Stat Card، Button، Input، Select، Badge، Table، Toolbar، Modal، Drawer، Toast، Empty State، Skeleton، Dropdown و Tabs.

## Buttons
Primary برای عملیات اصلی، Secondary برای جایگزین، Ghost برای عملیات سبک و Danger برای عملیات مخرب.

## Responsive
mobile < 768، tablet 768–1199، desktop >= 1200.

## Theme
Light/Dark با CSS custom properties؛ انتخاب در localStorage نگهداری و با prefers-color-scheme سازگار شود.

## Motion
Transition کوتاه و هدفمند؛ انیمیشن تزئینی طولانی در POS ممنوع.
