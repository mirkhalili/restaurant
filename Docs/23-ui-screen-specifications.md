# مشخصات صفحات رابط کاربری

## Dashboard
Header + KPI Cards + ویجت‌های فروش/عملیات + آخرین سفارش‌ها + Quick Actions.

## Orders
Toolbar + Filter + Status Tabs + Table + Create/Edit Drawer + Order Detail.

## POS
Category/Product + Cart + Customer + Discount + Payment Summary.

## Customers
Search + Filters + Table + Detail Drawer + Purchase History.

## Products
Category Filter + Table/Card + Price/Status + Create/Edit Form.

## Inventory
Stock KPI + Low-stock Alert + Movement Table + Adjustment Dialog.

## Kitchen
Kanban سفارش‌ها: جدید، در حال آماده‌سازی، آماده، تحویل.

## Reports
Filter Bar + KPI + Chart/Table + Export.

## Users & Roles
User List + Role Assignment + Permission Matrix + Scope.

## Settings
گروه‌بندی تنظیمات؛ تغییرات حساس با Confirm و Audit.

## Common states
loading: skeleton؛ empty: پیام + CTA؛ error: پیام + Retry؛ success: toast.
