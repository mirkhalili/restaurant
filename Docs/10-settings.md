# تنظیمات

## عمومی
نام، لوگو، تماس، زبان، منطقه زمانی، واحد پول، تاریخ و ساعت.

## رستوران
شعب، سالن، میز، ساعات کاری، شماره‌گذاری و انواع سفارش.

## فروش
مالیات، عوارض، تخفیف، حداقل مبلغ، هزینه ارسال و گرد کردن.

## غذا
واحد، دسته، منو، قیمت، قیمت ویژه، افزودنی و موجود/ناموجود.

## صندوق
صندوق، شیفت، روش پرداخت، محدودیت‌ها و قالب فاکتور.

## چاپ
Printer، Routing، Template، تعداد نسخه، Auto-print و Retry.

## Caller ID
Device/Agent، آدرس یا پورت، Timeout، Retry و Normalize.

## کاربران
Role، Permission، Session، PIN و محدودیت شعبه/صندوق.

## انبار
انبار، واحد، Recipe، روش مصرف و حداقل موجودی.

## سیستم
Backup، نگهداری لاگ، Import/Export، API و سلامت سرویس‌ها.
