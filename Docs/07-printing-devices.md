# چاپگرها و تجهیزات

## فیش‌پرینتر
پشتیبانی از چند چاپگر با مقصدهای مستقل:
- صندوق
- آشپزخانه
- بار
- سالن
- بسته‌بندی
- تحویل

## Routing
هر گروه محصول می‌تواند به چاپگر متفاوت ارسال شود. یک سفارش می‌تواند چند Print Job داشته باشد.

## اتصال
Windows Shared Printer، USB، Network/TCP، Local Print Agent و ESC/POS در صورت پشتیبانی.

## Print Job
هر Job شامل مقصد، قالب، سند، تعداد نسخه، وضعیت، زمان، خطا و Retry باشد.

## قالب‌ها
فیش آشپزخانه، رسید مشتری، فاکتور، گزارش صندوق، برچسب و بسته‌بندی.

## تنظیمات
عرض کاغذ، Encoding، Cut، Feed، Logo، QR/Barcode، Header/Footer، تعداد نسخه، Auto-print و چاپ مجدد.

## Caller ID
دستگاه یا Agent باید پشت Adapter مستقل باشد تا تغییر برند سخت‌افزار نیازمند تغییر هسته سامانه نباشد.
