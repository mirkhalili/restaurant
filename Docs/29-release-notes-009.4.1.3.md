# Release Notes — 009.4.1.3

## CSV Encoding Fix

- ورودی CSV اکنون **فقط UTF-8** است.
- هرگونه تبدیل Encoding با `mb_convert_encoding()` از مسیر Import حذف شد.
- فایل UTF-16 یا فایل با Encoding نامعتبر با پیام فارسی واضح رد می‌شود.
- بنابراین خطاهای مربوط به Encodingهایی مانند `CP1256` یا `Windows-1256` دیگر از کد Import ایجاد نمی‌شوند.

## QAVNS

نسخه این اصلاح: **`009.4.1.3`**.

طبق QAVNS، این یک اصلاح باگ است؛ شماره سمت چپ یک واحد افزایش یافته و CCC نیز یک واحد افزایش یافته است.
