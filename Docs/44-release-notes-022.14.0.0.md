# Release Notes — 022.14.0.0

## فیش آشپزخانه
- ستون «نوع سفارش» از جدول فیش حذف شد.
- هر بخش/دسته با آیکون انتخاب‌شده برای همان دسته در کنار عنوان نمایش داده می‌شود.
- عنوان دسته کوچک‌تر و پررنگ‌تر شده است.
- نام محصولات بزرگ‌تر شده است.
- محصولات دسته‌های غذایی با عنوان شامل «غذا» با اندازه فونت بزرگ‌تر نمایش داده می‌شوند.
- عبارت «مخصوص آشپزخانه — بدون قیمت» و تنظیم متن پایانی آن از فیش حذف شد.
- دکمه «داشبورد» به نوار ابزار پیش‌نمایش چاپ اضافه شد.

## آیکون دسته‌بندی
- در تنظیمات > انواع محصول، آیکون دیگر ورود دستی نیست.
- مجموعه‌ای از آیکون‌های غذایی، نوشیدنی، بسته‌بندی و عمومی برای انتخاب در دسترس است.
- انتخاب آیکون هنگام ایجاد و ویرایش دسته اعتبارسنجی می‌شود.
- آیکون انتخاب‌شده در فیش آشپزخانه نیز استفاده می‌شود.

## ثبت سفارش
- فیلتر اولیه محصولات به جای «همه»، روی «غذا» قرار گرفت.
- فیلتر «غذا» دسته‌هایی را که عنوانشان شامل «غذا» است نمایش می‌دهد.
- هنگام ورود به صفحه ثبت سفارش بدون فاکتور فعال، محصولات پیش‌فرض نوع سفارش به‌صورت خودکار وارد فاکتور می‌شوند.
- هنگام زدن «فاکتور جدید» نیز محصولات پیش‌فرض بر اساس نوع سفارش فعال (سالن/بیرون‌بر) به فاکتور جدید اضافه می‌شوند.
- تغییر نوع سفارش، اقلام قبلی را حفظ کرده و محصولات پیش‌فرض نوع جدید را نیز اضافه می‌کند.
