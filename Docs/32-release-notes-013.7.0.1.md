# Release Notes — 013.7.0.1

## اصلاحات و تغییرات

- اصلاح امن داده‌های موجود مشتریان و محصولات برای تبدیل حروف عربی ي/ى/ك به ی/ی/ک.
- از تبدیل اشتباه ئ جلوگیری شد.
- انتقال ساختار دسته‌بندی محصول به «نوع محصول» (products.product_type) انجام شد؛ ستون زائد category_id حذف می‌شود.
- رنگ و تعریف انواع همچنان از product_categories مدیریت می‌شود و ارتباط با محصول بر اساس نام نوع انجام می‌شود.
- در POS، ابتدا مشتری باید انتخاب یا ثبت شود؛ تا قبل از آن لیست محصولات نمایش داده نمی‌شود.
- پس از انتخاب مشتری، پنل انتخاب مشتری پنهان است و لیست محصولات فعال می‌شود.
- امکان انتخاب چند محصول و انتقال گروهی آن‌ها به یک نوع/دسته‌بندی اضافه شد.
- تغییر نام یا حذف یک نوع، product_type محصولات را نیز به‌صورت سازگار به‌روزرسانی می‌کند.
- بخش تعریف کاربران با نقش، وضعیت، ایمیل، موبایل و رمز عبور اضافه شد.
- صفحه «پروفایل من» برای تغییر نام نمایشی، ایمیل، موبایل و رمز عبور اضافه شد.
- فیلدهای پروفایل کاربران با Migration قابل اجرای مجدد اضافه می‌شوند.
