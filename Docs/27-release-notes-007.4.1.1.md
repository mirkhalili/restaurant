# Release Notes — 007.4.1.1

## CSV Import Fix

- بهبود ورود CSV مشتریان و محصولات برای فایل‌های خروجی Excel و CSV فارسی.
- پشتیبانی از جداکننده‌های رایج کاما، سمی‌کالن، Tab و Pipe.
- پشتیبانی از BOM و Encodingهای رایج UTF-8 و UTF-16.
- نرمال‌سازی حروف فارسی/عربی در سربرگ‌ها.
- نرمال‌سازی ارقام فارسی و عربی برای شماره تلفن و قیمت.
- پشتیبانی از نام‌های متداول فارسی و انگلیسی برای ستون‌های مشتریان و محصولات.
- نمایش خطای قابل فهم در صورت شناسایی نشدن ستون‌های CSV.
- استفاده از تراکنش هنگام ورود گروهی داده‌ها.
